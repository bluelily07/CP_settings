## Динамическое Программирование

ДП - это способ решать задачи, разбивая их на **подзадачи**, которые повторяются. Вместо того чтобы каждый раз пересчитывать одну и ту же подзадачу заново (как в рекурсии), мы один раз считаем результат и **запоминаем** его. Полученный ответ используем в решении следующей подзадачи, не пересчитывая все с нуля.

## Виды ДП

Одномерное ДП - когда состояние описывается одним числом (индексом), и `dp[i]` хранит ответ для этого индекса. Это самый базовый и самый частый вид ДП. 

То есть у ДП есть только один хранимый параметр, у двухмерного ДП - два параметра, у трехмерного - три и т.д

## Способы реализации одномерного ДП

Примеры реализаций будут написаны для чисел Фибоначчи.

**Формула чисел Фибоначчи** - ```fib[i] = fib[i-1] + fib[i-2];```
где ```fib[0] = 0; fib[1] = 1;```

1. **Мемоизация**

Мемоизация - рекурсия с запоминанием результата. Проверяем, считали ли мы это состояние раньше? Если да - берем ответ из памяти, иначе считаем и записываем в память 

```cpp
vector<ll> mem;
vector<bool> visited;

ll solve(int n) {
    if (n <= 1) return n;//базовый случай рекурсии (fib0 = 0, fib1 = 1)
    if (visited[n]) return mem[n];//Если мы уже считали это, то просто берем из памяти, не считая заново.
    visited[n] = true;//иначе ставим флаг посещенности 
    mem[n] = solve(n - 1) + solve(n - 2);// и рекурсивно считаем 
    return mem[n];
}
```
2. **Табуляция**

Никакой рекурсии, считаем ДП от малых значений к большим, используя уже известные данные

```cpp
vector<ll> dp(n + 1)
dp[0] = 0;
if (n >= 1) dp[1] = 1;//создаем вручную два базовых значения
for (int i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];//заполняем ДП без рекурсии на основе известных значений
}
```

**Пару слов об реализациях:**
1. Чаще всего на практике - мемоизацию легче придумать.
2. Мемоизация дороже табуляции из-за доп. вызовов функций, дороже по памяти
3. При глубокой рекурсии мемоизация может словить stack overflow
4. Табуляция часто работает быстрее мемоизации
5. При табуляции можно не хранить весь массив, а только необходимые элементы для подсчета ДП.
6. При табуляции легче контролировать память 

## Разбор задач на одномерное ДП

Существует прямая пронумерованная от 0 до n. Стоя на позиции i, можно прыгнуть на позиции i+1 или i+2 или i+k. (k <= n, k != 1, k != 2).
Сколько существует различных последовательностей прыжков, чтобы добраться из позиции 0 в позицию n?

**Решение:**
Для начала, обозначим состояние ДП и базовое состояние.

`dp[i]` - количество различных последовательностей прыжков, чтобы попасть из позиции 0 в позицию i. - это наше состояние ДП.


`dp[0] = 1` - т.к, мы уже стоим на позиции 0, способов попасть на эту позиции всего один. Мы же начинаем с него. - Это наше базовое состояние.

Теперь мы должны обозначить переход состояний.

Чтобы оказаться в позиции i, последний прыжок был длиной 1, 2 или k. Значит, мы попали в i либо из `i-1`, либо из `i-2`, либо из `i-k`. Эти три случая не пересекаются между собой (у путей разная длина последнего прыжка — значит, это разные последовательности), и вместе покрывают все способы добраться до i. Поэтому их количества складываются:

```
dp[i] = dp[i-1] + dp[i-2] + dp[i-k]
```
При этом, важно чтобы позиция которую мы используем существовала, то есть была >= 0. - Это и есть переход состояний.

```cpp
void solve() {
    int n, k;
    cin >> n >> k;

    vector<ll> dp(n + 1, 0);
    dp[0] = 1;

    for (int i = 1; i <= n; i++) {
        if (i - 1 >= 0) dp[i] = (dp[i] + dp[i - 1]);
        if (i - 2 >= 0) dp[i] = (dp[i] + dp[i - 2]);
        if (i - k >= 0) dp[i] = (dp[i] + dp[i - k]);
    }

    cout << dp[n] << "\n";
}
```
