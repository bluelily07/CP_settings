> Конспект по битовым операциям: как они работают на уровне битов, и какие практические трюки с ними связаны (особенно с XOR).

## Базовые операции

**AND (&)** - побитовое И. Бит результата равен 1, только если в обоих числах на этой позиции стоит 1. Используется, чтобы "оставить" только нужные биты (маска).

```
1010
0110
----
0010
```

**OR (|)** - побитовое ИЛИ. Бит результата равен 1, если хотя бы в одном из чисел на этой позиции стоит 1. Используется, чтобы "включить" (установить) биты.

```
1010
0110
----
1110
```

**XOR (^)** - побитовое исключающее ИЛИ. Бит результата равен 1, если биты чисел на этой позиции разные (один 0, другой 1). Если биты одинаковые - результат 0.

```
1010
0110
----
1100
```

**NOT (~)** - побитовое отрицание, переворачивает все биты (0 -> 1, 1 -> 0). Для чисел со знаком в C++ это то же самое, что `-x - 1`.

## Сдвиги

**`x << k`** - сдвиг влево на k позиций, то есть все биты сдвигаются влево, а справа дописываются нули. Это то же самое, что умножить x на 2^k.

**`x >> k`** - сдвиг вправо на k позиций, отбрасывает k младших битов. Это то же самое, что целочисленно поделить x на 2^k.

## Свойства XOR

Это то, что делает XOR особенным и часто встречается в задачах:

- `x ^ 0 = x` - XOR с нулём ничего не меняет
- `x ^ x = 0` - XOR числа с самим собой обнуляет
- `x ^ y = y ^ x` - коммутативность
- `(x ^ y) ^ z = x ^ (y ^ z)` - ассоциативность, поэтому порядок XOR-ов не важен

Из первых двух свойств следует практический трюк: если в массиве все числа встречаются парами, кроме одного, то XOR всех элементов массива даст это одно число (пары взаимно уничтожатся, останется только оно).

```
for (int x : a) res ^= x;
```

## Полезные трюки

**Проверить i-й бит:**

```
(x >> i) & 1
```

Сдвигаем нужный бит на нулевую позицию, а всё остальное отбрасываем через `& 1`.

**Установить i-й бит в 1:**

```
x | (1 << i)
```

**Снять i-й бит (поставить 0):**

```
x & ~(1 << i)
```

**Посчитать количество единичных битов:**

```
__builtin_popcount(x)
```

Для `long long` - `__builtin_popcountll(x)`.
