## Виды графов





Ориентированный граф - ребро = мат. вектор, одностороннее движение.
\
\
Неориентированный граф - двухстороннее движение.
\
\
Невзвешенный граф - ребра просто существуют, или не существуют.
\
\
Взвешенный граф - у каждого ребра есть собственный вес.
\
\
Ациклический граф - граф без циклов. Если такой граф ориентированный, то у него есть название DAG (Directed Acyclic Graph).
\
\
Связный граф - из любой вершины можно добраться до любой другой
\
\
Несвязный граф - распадается на несколько "островов" - компонент связности
\
\
Дерево - Ациклический связный граф. При n вершин имеет n-1 ребро.



## Термины



Степень вершины - сколько ребер выходит из этой вершины
\
\
Путь - последовательность вершин, где есть коннект с ребрами
\
\
Простой путь - путь без повторяющихся вершин
\
\
Цикл - это путь, который начинается и заканчивается в одной и той же вершине, не повторяя рёбра.(не повторяя ребра, потому-что тогда любые две вершины могли бы быть циклом: 1-2; 2-1)
\
\
Простой цикл - Цикл, который вдобавок повторно не проходит через посещенные вершины в этом цикле.
\
\
Смежные вершины - вершины, соединенные общим ребром



## Способы хранения графов



1. Матрица смежности (adjacency matrix)
```cpp
vector<vector<int>> adjmatrix(int n, int m) {
    vector<vector<int>> adj(n + 1, vector<int>(n + 1, 0)); //создаем матрицу, с помощью n+1 переходим в 1 индексацию, можно остаться в 0, но тогда после считывания данных, уменьшаем их на 1. (u--; v--)

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;//считали данные
        adj[u][v] = 1;
        adj[v][u] = 1;//ставим 1 на месте ребра, не забываем поставить единицу зеркально первой, тк матрица зеркальна.
    }

    return adj;//буллевая матрица, в отличии от интовой, дешевле примерно в 32 раза по памяти, но скорость обращения к такой матрице несильно падает из-за доп. битовых вычислений.
    //В задачах когда мы используем матрицу смежности ради доступа O(1), берем буллевую матрицу, в очень редких специффицеских алгоритмах, когда нужна скорость обращения, берем int или char
}
```
2. Список смежности (adjacency list)
```cpp
vector<vector<int>> adjlist(int n, int m) {
    vector<vector<int>> adj(n + 1);

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    return adj;
}
```
3. Список ребер (edge list)
```cpp
vector<pair<int,int>> edgelist(int m) {
    vector<pair<int,int>> edges;

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        edges.push_back({u, v});
    }

    return edges;
}
```


## Основные алгоритмы обхода 



DFS - идея: заходим в вершину, из неё идём в первого непосещенного соседа максимально глубоко, и только когда попадаем в тупик - возвращаемся и пробуем следующего соседа.

BFS - идея: обходим граф слоями, сначала все вершины на расстоянии 1 от старта, потом все на расстоянии 2, и тд, используем фифо очередь.



## Лемма о рукопожатиях 



Сумма всех степеней вершин в графе = количеству ребер в графе \* 2. Отсюда получаем утверждение: сумма степеней всех вершин в любом графе это четное число.



**Задача о королевстве**



В королевстве есть 1001 деревня, король хочет чтобы из каждой деревни выходило ровно по 7 дорог. Возможно ли осуществить его идею? Обоснуйте ответ

Ответ: Нет, нельзя. Сумма степеней всех деревень была бы 1001 \* 7 = 7007, а исходя из леммы о рукопожатиях, сумма степеней должна быть четная.



## Код базовых алгоритмов обхода 



**DFS** (рекурсивно)

```cpp
void dfs(int v) {
    visited[v] = true; //берем вершину и помечаем ее посещенной
    
    for (int to : graph[v]) { // смотрим соседей этой вершины
        if (!visited[to]) { // если мы не были у соседа этой вершины
            dfs(to); // рекурсивно помечаем его посещенным
        }
    }
}
```

**BFS**

```cpp
void bfs(int start) {
    vector<int> q; // создаем очередь
    visited[start] = true; // помечаем стартовую вершину посещенной
    q.push(start); // добавляем в очередь
    
    while (!q.empty()) {
        int v = q.front();
        q.pop(); // запоминаем вершину из очереди и удаляем ее
        
        for (int to : graph[v]) { // проверяем всех соседей этой вершины
            if (!visited[to]) {
                visited[to] = true;
                q.push(to); // если мы не были у соседа этой вершины, помечаем его посещенным и добавляем в очередь
            }
        }
    }
}
```
